# Farhad Ali — Anime Portfolio Plus

Anime-inspired personal portfolio site for **Farhad Ali**, a software developer focused on JavaScript, React, and modern web projects.

## Sections

- **Home** — Introduction and social links
- **About** — Bio aligned with [GitHub profile](https://github.com/Farhadali123)
- **Projects** — React Movie App, Fruit Ninja, Coffee Website
- **Services** — Web development and performance optimization
- **Contact** — Email and GitHub

## Tech stack

- HTML, CSS, JavaScript (Vanilla JS)
- Font Awesome
- Responsive layout and scroll animations

## How it works

- `index.html` contains the portfolio sections, navigation, project cards, contact details, and external links.
- `style.css` controls the neon anime-inspired visual design, responsive layout, animations, and mobile navigation.
- `script.js` powers the intro loading screen, scroll reveals, smooth navigation, project filtering, counters, and contact form behavior.
- Images are stored in `porotofilo8/images/` and referenced by the project cards in `index.html`.

## Run locally

Open `porotofilo8/index.html` in your browser, or run a local static server from the `porotofilo8` folder. For example:

```bash
cd porotofilo8
python -m http.server 8000
```

Then visit `http://localhost:8000`.
